Review the Code

  1. Line 7: Can you add parameters to the method (drawFrame)?

Yes, the drawFrame function can accept parameters such as position, speed, or rotation angle. For instance:

function drawFrame(x, angle)

This allows more flexibility by passing updated values each frame instead of relying only on global variables.

  1. Why are there two calls to “requestAnimationFramf” (Lines 5 and 20)?

The first call (Line 5) starts the animation by invoking drawFrame for the first time. The second call (Line 20) keeps the animation running by repeatedly requesting the next frame, creating a loop until the condition ( circleX < 150 ) is no longer true.
